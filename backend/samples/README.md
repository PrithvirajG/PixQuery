# Sample images

A small set of real images for trying PixQuery end-to-end. Point a workspace at
this folder (its absolute path) to ingest, process, and search these files.

See the "Manual end-to-end smoke test" section of the repository `README.md` for
the full walkthrough. For the fast, infra-free wiring check, run
`python -m unittest tests.test_smoke_search` instead.
