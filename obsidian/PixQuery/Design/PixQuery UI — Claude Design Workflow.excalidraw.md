0  Prime the system ^st0_h

Generate App Shell + nav, then the ⌘K command palette. Lock them. ^st1_b

2  Screens, one at a time ^st2_h

Search → Image Detail → Workspaces → Pipelines → Jobs → Landing → Settings.
Paste each §8 screen section verbatim. ^st2_b

3  Generate the states ^st3_h

For each screen: loading (skeletons), empty, error, and each modal/drawer — one prompt each. ^st3_b

Targeted notes, not full regen. Reference principles by name
(“content is the light source”, “one accent, used with discipline”). ^st4_b

Export Tailwind tokens + component list → map to React, wire real API data, replace screen by screen. ^st5_b

  match-reason chips, node chain,
